# Adas Körper-Atlas

Interaktive Lernwelt für Sachkunde, Klasse 3: **Der menschliche Körper** – Skelett, Wirbelsäule, Gelenke, Muskeln, Organe, Blutkreislauf, Atmung, Verdauung, Haut, Wahrnehmung und Sonne.

- Eine einzige HTML-Datei (`index.html`): läuft offline, kein Login, keine Datenübertragung. Der Lernfortschritt bleibt nur lokal im Browser.
- Modi: Lernen, Kapiteltraining, Bildquiz, Karteikarten, Probeprüfung, Fragenkatalog, Fehlertraining – plus Elternbereich mit Anleitung, Abdeckungsmatrix und Korrekturliste.
- Inhalte und Logik liegen in `src/`. Bauen: `node build.mjs` · Prüfen: `node tests/test.mjs`
